# AuraTax T2 rules register

Generated by `tools/extract.py` from AuraTax 2.3.33 (`fixtures/t2/`). AuraTax's reading of the forms, not the forms themselves: a cross-check only.

- `schedules/<code>.md`: one page per schedule, lines in form order
- `lines.csv`: every line, with the raw rule JSON beside the plain-English gloss
- `flows.csv`: every declared flow between schedules (`_origin` = comes from, `_reportOn` = goes to). `marker` = ∞ means the other end is on the linked provincial return, not this return.
- `rates.json`: AuraTax's rate table (`refs/calculate-params.json`)

**172 schedules, 6981 numbered lines, 1471 rules, 1655 flows.**

What is not here: the calculation formulas. Totals marked `total`/`subtotal` and lines marked `calculated` are computed in the app's code (`main.js`), not in this data.
